1. IEEE

1.1. Concepto

El estándar IEEE 754 es la representación más utilizada actualmente para números en punto flotante en computadoras, incluyendo PCs con procesadores Intel o AMD, sistemas Mac y la mayoría de plataformas Unix.

IEEE 754 define una representación eficiente basada en tres componentes principales:

1. Bit de signo: indica el signo del número. Un valor de 0 representa un número positivo y 1 un número negativo.

2. Exponente sesgado: permite representar exponentes positivos y negativos mediante el uso de un sesgo (bias) de 127, el cual se suma al exponente real para obtener el valor almacenado.

3. Mantisa o fracción normalizada: representa los bits significativos del número en base 2. En números normalizados, existe un 1 implícito a la izquierda del punto decimal que no se almacena explícitamente.

A continuación se presenta una herramienta interactiva que permite ingresar un número decimal y obtener su representación en formato IEEE 754 de 32 bits.

2. Proceso manual de conversión

El formato IEEE 754 usa 32 bits(precisión simple):

  • 1 bit de signo (S)
  • 8 bits de exponente (E) = 127
  • 23 bits de mantisa (M)

La representación final es: 

S | EEEEEEEE | MMMMMMMMMMMMMMMMMMMMMMM

2.1. Paso 1: Determinar el signo

  • Si el número es positivo: S = 0
  • Si el número es negativo: S = 1

2.3. Paso 3: Convertir la parte entera a binario

Usamos divisiones sucesivas entre 2 y tomamos los residuos de abajo hacia arriba.

Ejemplo (entero 13): 

13/2=6 r1

6/2=3 r0

3/2=1 r1

1/2=0 r1

13 = 1101

2.4. Paso 4: Convertir la parte fraccionaria a binario

Multiplicar repetidamente por 2 y tomar la parte entera en cada paso.

Ejemplo (0.625): 

0.625×2 = 1.25    bit 1

0.25×2  = 0.5     bit 0

0.5×2   = 1.0     bit 1

0.625 = 0.101

2.5. Paso 5: Unir entero y fracción

Combinar: N = (entero).(fracción) en binario

Ejemplo: 

13.625 -> 1101.101

2.6. Paso 6: Normalizar

Mover el punto binario hasta que quede un solo 1 a la izquierda: 

1101.101 = 1.101101 *  2^3
  • El exponente real es 3.

2.7. Paso 7: Calcular el exponente con bias

En precisión simple: 

E = n + 127

Ejemplo: 

n = 3 ->  E = 3 + 127 = 130

Convertir 130 a binario (8 bits): 

130 = 10000010

2.8. Paso 8: Calcular la mantisa

La mantisa son los bits después del “1.” en la normalización, rellenando con ceros hasta completar 23 bits.

Ejemplo: 

1.101101 -> mantisa = 10110100000000000000000 (23 bits)

2.9. Paso 9: Construir el número IEEE 754 final

Concatenar: 

S (1 bit) | E (8 bits) | M (23 bits)

Ejemplo final (13.625): 

S = 0

E = 10000010

M = 10110100000000000000000


IEEE 754:

0 10000010 10110100000000000000000

<script>
function convertir() {
  let valor = parseFloat(document.getElementById("decimal").value);

  if (isNaN(valor)) {
    alert("Ingrese un número válido");
    return;
  }

  let buffer = new ArrayBuffer(4);
  let view = new DataView(buffer);
  view.setFloat32(0, valor);

  let binario = "";
  for (let i = 0; i < 4; i++) {
    let byte = view.getUint8(i).toString(2).padStart(8, "0");
    binario += byte;
  }

  document.getElementById("binario").innerText = binario;
  document.getElementById("signo").innerText = binario.substring(0, 1);
  document.getElementById("exponente").innerText = binario.substring(1, 9);
  document.getElementById("mantisa").innerText = binario.substring(9);
}
</script>
